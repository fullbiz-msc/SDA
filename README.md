# SDA — System Design Audit

Устанавливаемый навык для Codex и Claude Code: аудит системного дизайна существующих проектов, рекомендации и архитектурный отчёт **без самостоятельных исправлений**.

SDA изучает фактическую структуру и потоки данных, оценивает нагрузку, согласованность, масштабирование, надёжность, эксплуатацию, безопасность и стоимость. Проверяет каждый ID включённого архитектурного стандарта 1.1.0. Не навязывает Redis, Kafka, микросервисы или шардинг без обоснования. Для отсутствующих метрик пишет UNKNOWN, а не выдумывает ёмкость или класс системы.

## Быстрый старт через агента

Передайте агенту с доступом к проекту:

```text
Установи навык sda из https://github.com/fullbiz-msc/SDA:
для Codex используй каталог codex/sda,
для Claude Code — claude/sda.
Прочитай пакет, скопируй каталог целиком вместе с references
в поддерживаемую твоей средой папку навыков.
Не перезаписывай существующий sda без согласования.
Проверь наличие SKILL.md и всех references после установки.
Если текущая сессия не видит навык, сообщи об этом.

Затем используй SDA для архитектурного аудита текущего проекта.
Код, данные, конфигурации и инфраструктуру не меняй.
Не запускай приложение, тесты, нагрузку или запросы к сервисам.
Дай рекомендации и SDA-REPORT.md.
Отчёт сохраняй только в явно указанное разрешённое место;
если оно не задано, выдай отчёт в чате.
```

Доступ к модели/агенту и проекту нужен отдельно. Ссылка не устанавливает навык сама. Навык не является самостоятельным сканером или технической песочницей. Этот репозиторий не содержит движка ИИ и не предоставляет подписку.

## Ручная установка

Скачайте/клонируйте репозиторий и из его каталога выполните одну команду. Нужен Python 3.10+, сторонние Python-пакеты и сеть для копирования не нужны.

```sh
python3 install.py --agent codex
```

или

```sh
python3 install.py --agent claude
```

Установщик копирует только соответствующий пакет в `~/.agents/skills/sda` для Codex или `~/.claude/skills/sda` для локального Claude Code. Существующий каталог не перезаписывает, настройки агента и проверяемые проекты не меняет. Папку можно выбрать явно: `python3 install.py --agent codex --destination /absolute/path/to/skills/sda`.

Эти расположения и синтаксис вызова описаны в официальных документациях [Codex](https://learn.chatgpt.com/docs/build-skills) и [Claude Code](https://code.claude.com/docs/en/skills), проверенных 2026-11-11. Управляемые политики или облачная среда могут ограничивать загрузку локальных навыков.

После установки откройте сессию в нужном проекте и вызовите `$sda` в Codex или `/sda` в Claude Code. Проверьте, что агент прочитал SKILL.md и включённый стандарт. Если навык не появился, начните новую сессию и проверьте политику загрузки; успешное копирование файлов само по себе не доказывает активацию в конкретном приложении.

Для проектной установки используйте `--destination /path/to/project/.agents/skills/sda` либо `/path/to/project/.claude/skills/sda` **по отдельному поручению на установку**. Такая запись — настройка, а не действие read-only аудита. Не устанавливайте навык внутрь проекта в рамках задания «только проверить» без разрешения на эту запись.

## Что в отчёте

- Реестр репозиториев, SHA и рабочих изменений, среды и ограничения охвата.
- Фактическая структура, ответственность и существенные зависимости.
- Профиль нагрузки и отдельная критичность; SLO, RTO/RPO, запас ёмкости только по доказательствам.
- Полная матрица ID: PASS, FAIL, PARTIAL, UNKNOWN, N/A с основаниями и E-ID.
- Находки с P0–P3 и уверенностью, что сохранить, простые альтернативы и критерии приёмки.
- Поэтапные рекомендации с рисками, совместимостью, стоимостью и необходимыми следующими проверками.
- Декларация фактически выполненных действий; никаких придуманных тестов, исправлений и production-гарантий.

Скилл может анализировать уже предоставленные метрики и результаты CI. Не получает их автоматически из production. Любые отдельно порученные активные проверки требуют границ и оценки побочных эффектов; аудит не превращается в реализацию.

## Состав и источник

```text
codex/sda/SKILL.md
codex/sda/references/ARCHITECTURE_STANDARDS.md
codex/sda/references/report-template.md
codex/sda/references/provenance.json
claude/sda/…                    # самостоятельный эквивалентный пакет
install.py
tests/test_install.py
```

Стандарт предоставлен владельцем проекта: версия 1.1.0 от 2026-11-08. Он включён без изменений; SHA-256 и происхождение закреплены в `references/provenance.json`. Локальные пути автора и личные правила сессий в пакет не входят. Требования проектирования/реализации в исходном стандарте используются как критерии аудита, а не полномочия на исправления. При обновлении стандарта нужно отдельно оценить необходимость повторного аудита.

## Проверка пакета

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют установку пакета и защиту существующего каталога. Они не измеряют качество архитектурных выводов модели. Реальную загрузку в агенте и полноценный аудит нужно проверять отдельно; отсутствие дефектов не гарантируется. Лицензия MIT.
